# Spec-Driven Development (SDD) en Gemstack

Este directorio maneja el flujo de diseño antes del código.

## `specs/current/`
Aquí residen los documentos de la funcionalidad en desarrollo actual. Siempre deben estar sincronizados.
- `spec.md`: El "Qué" y "Por qué".
- `plan.md`: El diseño técnico ("Cómo").
- `tasks.md`: El desglose ejecutable.

## `specs/templates/`
Contiene las plantillas base utilizadas por los skills `/specify`, `/plan` y `/tasks` para inicializar los documentos en `current/`.
